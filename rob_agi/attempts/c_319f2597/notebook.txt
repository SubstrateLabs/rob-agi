Challenge 319f2597: Transform input grid into L-shaped black region

What we know:
1. The input is a 20x20 grid of colored cells (0-9).
2. The output should have an L-shaped black region.
3. The vertical part of the L is always on the right side of the grid.
4. The horizontal part of the L is always in the upper half of the grid.
5. Existing black cells (0) in the input should be preserved in the output.

What we've learned from the latest test:
1. The vertical stripe should extend from top to bottom of the grid.
2. The horizontal stripe should extend from the left edge to the vertical stripe.
3. The intersection of the vertical and horizontal stripes should be fully black.
4. We need to be more careful about preserving original black cells.

What doesn't work:
1. Simply creating the L-shape without considering existing black cells.
2. Using only the rightmost columns for the vertical stripe without checking for existing black cells.

What we need to improve:
1. The algorithm for determining the position of the vertical stripe.
2. The algorithm for determining the position of the horizontal stripe.
3. The way we preserve existing black cells while creating the L-shape.

Next steps:
1. Refine the vertical stripe selection to consider existing black cells in the right half of the grid.
2. Refine the horizontal stripe selection to consider existing black cells in the upper half of the grid.
3. Ensure that the L-shape extends fully to the edges of the grid.
4. Implement a more robust method to preserve existing black cells.
