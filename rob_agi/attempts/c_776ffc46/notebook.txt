Challenge 776ffc46: Transform blue regions in a grid

Updated Rules:
1. Blue regions (color 1) of size 2-4 pixels should be changed to the target color (red or green).
2. Blue regions of exactly 5 pixels should be changed to the target color only if they form a plus shape.
3. The target color (red or green) depends on which color is more prevalent in the entire input grid.
4. Larger blue regions, single blue pixels, and other colors should remain unchanged.
5. The transformation should be applied to all eligible blue regions simultaneously.
6. Gray (color 5) acts as a border and should not be considered part of any region.
7. Only orthogonally adjacent cells are considered part of the same region.
