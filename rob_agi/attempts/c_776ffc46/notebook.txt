Challenge 776ffc46: Transform blue regions in a grid

Updated Rules:
1. Blue regions (color 1) of size 2-8 pixels (inclusive) should be changed to red (color 2) or green (color 3).
2. The choice between red and green depends on which color is more prevalent in the entire input grid.
3. Larger blue regions, single blue pixels, and other colors should remain unchanged.
4. The transformation should be applied to all eligible blue regions simultaneously.
5. Gray (color 5) acts as a border and should not be considered part of any region.

Key observations:
- The grid size is 20x20.
- Gray (color 5) forms borders or structures that should not be modified or crossed when identifying regions.
- The prevalence of red vs green in the entire input grid determines the target color for transformation.
- The size constraint is 2-8 pixels, regardless of shape.
- Some blue regions should remain unchanged (those of size 1 or larger than 8).

Implementation steps:
1. Create a deep copy of the input grid.
2. Count the total number of red and green cells in the input grid to determine the preferred color.
3. Identify all blue regions using a depth-first search algorithm that respects gray borders.
4. For each blue region:
   a. Check if it's eligible for transformation (size between 2 and 8 pixels, inclusive).
   b. If eligible, mark it for transformation to the preferred color.
5. Apply all transformations simultaneously.
6. Return the transformed grid.

Current status:

- The size constraint (2-8 pixels) is correctly implemented.
- The transformation is applied simultaneously to all eligible regions.
- Gray borders are respected when identifying regions.
