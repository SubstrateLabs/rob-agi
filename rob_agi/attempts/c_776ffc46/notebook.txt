Challenge 776ffc46: Transform blue regions in a grid

Rules:
1. Blue regions (color 1) of size 2-9 pixels with maximum dimension <= 3 should be changed to red (color 2) or green (color 3).
2. Blue plus sign shapes (5 pixels in a cross pattern) should also be changed.
3. The choice between red and green depends on which color is more prevalent in the entire grid.
4. Larger blue regions, single blue pixels, and other colors should remain unchanged.
5. The transformation should be applied to all eligible blue regions simultaneously.

Key observations:
- The grid size is 20x20.
- Gray (color 5) often forms borders or structures that should not be modified.
- The prevalence of red vs green in the entire grid determines the target color for transformation.
- Plus sign shapes need special handling, as they are a specific case of eligible regions.

Implementation steps:
1. Create a deep copy of the input grid.
2. Count the total number of red and green cells to determine the preferred color.
3. Identify all blue regions using a depth-first search algorithm.
4. For each blue region:
   a. Check if it's eligible for transformation:
      - Size between 2 and 9 pixels (inclusive)
      - Maximum dimension (height or width) <= 3
      - Or if it forms a plus sign shape (5 pixels in a cross pattern)
   b. If eligible, transform it to the preferred color.
   c. Otherwise, leave it unchanged.
5. Return the transformed grid.
