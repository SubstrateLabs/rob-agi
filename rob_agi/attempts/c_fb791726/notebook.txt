Challenge fb791726:

The challenge involves transforming an input grid into an output grid with the following rules:

1. The output grid size is (2n) x (2n), where n is the input grid size.
2. A single green (3) separator row and column is added in the middle of the output grid.
3. Non-black cells from the input grid are copied to the output grid with the following transformations:
   - Top-left quadrant stays in place
   - Top-right quadrant moves to bottom-left
   - Bottom-left quadrant moves to top-right
   - Bottom-right quadrant stays in place
4. The rest of the grid is filled with black (0)
